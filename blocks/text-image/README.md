# text-image

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image first | `reverse` |
| Grey band | `grey` |
| Preserve line breaks | `pre-line` |
| No trailing line | `no-trailing-line` |
| Empty text box | `empty-text` |
| Empty image box | `empty-image` |
| Trailing space 1 | `trail-1` |
| Trailing space 2 | `trail-2` |
| Footer overflow | `footer-overflow` |
