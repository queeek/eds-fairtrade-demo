## Foundation (C0)

Source of every value: the gated canon (`stardust/prototypes/canon.css`, `canon.js`) plus the chrome parts of the per-archetype layers (breadcrumbs from the gender-equality layer, navigation teasers + link-less footer titles from at-de, footer logo slot from mt-en). - **Decode tier — chrome: template-slotted.** `blocks/header` and `blocks/footer` build the canon DOM (kebab-cased classes, same values) and move the authored nav/footer document nodes into it by role; the nav document is fetched as `.plain.html` and NOT decorated (no `labels` block JS needed). Clones are used only where the canon repeats a link (mobile drawer, mobile teasers).
- **Class renames forced by kebab-case collisions:** `.Icon` → `.svg-icon`, `.Input.icon` → `.input.with-icon`, `.Topbar--mainNavigation` → `.topbar-main-nav` (the nav itself stays `.topbar-main-navigation`), `.Topbar--search` → `.topbar-search-slot` (panel stays `.topbar-search`), `.FooterLinkList` → `.footer-link-list-box`. The canon `.Footer` root IS the footer block div (`footer .footer`).
- **Fonts:** Alegreya Sans (headings) and Exo 2 (body, variable) are SIL OFL 1.1 — self-hosted verbatim from the prototype assets (latin + latin-ext, all weights/italics the canon declares, 32 woff2) in `fonts/`, `@font-face` in `styles/fonts.css`. No substitution, no licensing alert. Metric fallbacks computed with fontTools, width-matched against Liberation Sans (Arial metrics): `exo-2-fallback` size-adjust 102.54 % / ascent 97.43 % / descent 19.6 %; `alegreya-sans-fallback` (Arial Bold reference, headings are 800–900) 83.97 % / 107.18 % / 35.73 %. Roboto demo fonts removed. `head.html`: the two canon font preloads (Exo 2 latin, Alegreya Sans 900 latin) as the brief asked, plus the source favicon (`favicon.svg`).
- **Layout tokens:** the source grid primitive became tokens (`--grid-columns/--grid-gap/--grid-padding`, `--max-width: 1920px` = DESIGN.json shell/container cap); every block grid uses them. `main` has no margin-top: the header reserves `--nav-height = --topbar-height` (72 / 104 ≥ 640) and the fixed topbar sits inside it; breadcrumbs are absolutely positioned at the header's bottom edge (y 104 / 72, as measured on the prototype).

**Decisions / deviations**
- Block JS inlines its helpers (no `scripts/ft-ui.js` import): the round-trip harness inlines block JS and cannot resolve module imports; the helpers are byte-equivalent copies of `el`/`icon`/`buildWave` behaviour.
- Images: authored as absolute source URLs (largest captured rendition) — 87 references, all 200 on a plain fetch (crawl tier `chrome`); manifest with captured local files: `stardust/rollout/units/archetypes-media.json`.
- Metadata: own last section per page (title from the capture, no capture description exists → none authored; nav/footer/breadcrumbs from `chrome-map.json`).
- gender-equality: the source's empty accordion item (header bar, no title, no content) is not authored — an empty row cannot survive DA; the section renders its title only.
- text-image: where the source Richtext is HTML (`<p>` + a trailing newline under `white-space: pre-line`, at-de and mt-en) the source paints one extra 1.6em line under the text; plain-text sources (index, gender-equality) do not. Not reproducible from authored content (both arrive as `<p>`); left at the plain-text geometry — judge at the published gate, candidate for the inconsistency register (~29 px per text-image on at-de/mt-en).
- `localize-links.mjs` run over the whole tree: 27 chrome docs gained root-relative links to the new pages (/, /at-de, …); the five pages' own internal targets are not in the tree yet and stay absolute until their pages are authored.
- Tooling fix in `stardust/scripts/deploy/qa-gate.mjs`: the schema unit-count matcher now skips `defaultContent` sections and uses each section's own position (it matched every TextImage to the first one).
- at-de qa-gate: the only FAIL is a `pageerror` thrown inside the third-party Taggbox social iframe (`api.taggbox.com` CORS) — identical on the gated prototype at :8791; not ours to fix.
- Harness round-trips run with `--styles stardust/.work/encode/harness-styles.css` (styles.css + fonts.css with absolute font URLs) — without the webfonts the classifier reads a heading's fallback face as a different look and reports ROLE SWAP on heading-for-styled-span upgrades.
